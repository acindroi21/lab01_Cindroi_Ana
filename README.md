# lab01_Cindroi_Ana
# description
This project is a Python application that reads numbers from keyboard input and also reads numbers from a text file.

# fatures
- read a sequence of numbers entered by the user
- read a two-dimensional array of numbers with user-defined rows and columns
- read numbers from a text file specified by the user
- Display an error message if the specified file does not exist

# requirements
- Python 3
- Git

# how to run it
1. Open a terminal in the project directory
2. Run the application: py main.py
3. Follow the prompts to enter a sequence of numbers, the array dimensions and values, and the text filename.

# text file example
Create a file named `numbers.txt` in the same directory as `main.py`, containing: 10 20 30 40 50.
When prompted for the filename, enter `numbers.txt`
# branches
- feature/console-input — keyboard input functionality
- feature/array-file-input — reading numbers from a text file
Both features are intended to be merged into `main`.
